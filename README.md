# Web Dev Projects

A collection of small front-end projects built while learning JavaScript and Tailwind CSS.
Open `index.html` to see the list, or jump straight into one of them.

| Project | What it does |
| --- | --- |
| [Weather app](projects/weather-app/) | Search any city and see the temperature, conditions, humidity and wind, with a full-screen background video that matches the sky. |
| [Stopwatch](projects/stopwatch/) | Start, stop and reset a timer accurate to the hundredth of a second. |

## Structure

```
web-dev-projects/
├── index.html              # landing page linking to each project
├── package.json            # dependencies and build scripts
├── .gitignore
├── src/
│   └── input.css           # Tailwind source — edit this
├── dist/
│   └── output.css          # generated stylesheet — don't edit by hand
└── projects/
    ├── stopwatch/
    │   ├── index.html
    │   └── script.js
    └── weather-app/
        ├── index.html
        ├── config.js       # API key
        ├── script.js
        └── assets/
            └── videos/     # clear, clouds, night, rain, snow, sunny
```

Every project folder holds its own `index.html`, so the folder name is the URL and
nothing has to be renamed when you deploy.

## Running it

Both projects use `fetch` and video files, which browsers block on `file://` URLs.
Use a local server instead of double-clicking the HTML:

```bash
npx serve .
```

Or in VS Code, install the **Live Server** extension, right-click `index.html`
and choose *Open with Live Server*.

## Rebuilding the CSS

`dist/output.css` is generated by Tailwind. After adding new classes to any HTML file:

```bash
npm install          # first time only
npm run dev          # rebuilds automatically as you edit
```

For a smaller file before deploying:

```bash
npm run build
```

`dist/output.css` is committed on purpose, so that hosts like GitHub Pages and Netlify
can serve the site without a build step. `node_modules/` is not — run `npm install`
to get it back.

## API key

The weather app uses [OpenWeatherMap](https://openweathermap.org/api). The key lives in
`projects/weather-app/config.js`. Any key in a browser app is visible to anyone who opens
DevTools, so keep it on the free tier and replace it if it gets abused. To use your own,
sign up and paste your key into that file.

## Notes

- Video filenames are all lowercase. Windows ignores capitalisation but Linux servers
  don't, so `Sunny.mp4` would 404 once deployed.
- The videos total about 120 MB. GitHub warns above 50 MB per file and rejects anything
  over 100 MB, so if you push this, either compress them (`ffmpeg -i in.mp4 -vf scale=1280:-2
  -crf 30 out.mp4`) or host them elsewhere and point `VIDEOS` in `script.js` at the URLs.
